## Sujet

Exploration d'un jeu de données CSV sur la santé mentale dans le monde. Définition de questions analytiques, connexion à Tableau, création de visualisations et conception d'une narration data-driven.

## Sources de données

Les données utilisées sont dans le dossier `BDD/` :
- **PIB par habitant** — Banque Mondiale (API_NY.GDP.PCAP)
- **Indice de développement humain** — PNUD (HDR25 Statistical Annex)
- **Dépenses de santé** — Banque Mondiale (API_SH.XPD.CHEX)
- **Charge de morbidité** — IHME Global Burden of Disease 2023
- **Urbanisation** — Banque Mondiale (API_SP.URB.TOTL)
- **Données historiques** — OGHIST 2025
